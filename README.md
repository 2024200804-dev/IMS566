SMART CAMPUS STUDENT PORTAL

1. Project Description

Smart Campus Student Portal is a responsive web application interface developed for IMS566 – Advanced Web Design Development and Content Management.

This project allows students to manage academic information through a simple and modern dashboard interface. The system includes login authentication, attendance tracking, assignment monitoring, course overview, and timetable management.

The application was developed using Bootstrap 5, HTML, CSS, and JavaScript.



2. Features Included

2.1 Authentication Page
- Login page with email and password
- Error feedback for invalid login
- Session-based authentication

2.2 Dashboard
- Overview statistics
- Course cards
- Recent announcements
- Responsive UI

2.3 Attendance Page
- Attendance table
- Attendance percentage
- Interactive chart visualization

2.4 Assignment Page
- Assignment tracking
- Status and priority indicators

2.5 Timetable Page
- Weekly timetable
- Download options
- Responsive layout

2.6 Dark Mode
- Toggle between Light Mode and Dark Mode
- Theme saved using Local Storage
